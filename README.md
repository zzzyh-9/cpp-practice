# C++ / Qt 实训作品集

前三周的 C++ 和 Qt 实训成果，包含两个课后项目和一组课堂练习。每周目录可以独立构建。

| 周次 | 项目 | 实现内容 |
| --- | --- | --- |
| 第 1 周 | [CSV 导入管道](week01-csv/) | UTF-8 / GBK 解析、字段校验、坏行收集、后台流式导入和取消 |
| 第 2 周 | [JSON 内存优化](week02-json/) | 对比 Simpleson 的原始版和优化版，记录序列化分配次数与申请字节数 |
| 第 3 周 | [Qt Widgets 课堂练习](week03-qt/) | 登录窗体、信号与槽，以及「拯救苹果」打字游戏的课堂原型 |

第 2 周的一个 50 字段对象测试中，紧凑序列化的堆分配从 107 次降到 51 次，累计申请量从 9,814 字节降到 3,632 字节。测量口径见项目说明。

「拯救苹果」仍在开发中。公开版使用程序绘制的界面和合成音频。
